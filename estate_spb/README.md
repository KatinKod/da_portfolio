# Анализ рынка недвижимости Санкт-Петербурга и Ленобласти

## 🎯 Цель проекта
Провести комплексный анализ рынка недвижимости Санкт-Петербурга и Ленинградской области для определения перспективных сегментов и сезонных тенденций. Результаты помогут агентству недвижимости разработать эффективную бизнес-стратегию выхода на новый рынок.

## 📋 Основные задачи
1. Провести разведочный анализ данных (EDA) схемы real_estate
2. Определить наиболее привлекательные сегменты недвижимости по времени активности объявлений
3. Проанализировать сезонные тенденции на рынке недвижимости
4. Разработать дашборд в DataLens для оперативного анализа рынка

## 🛠 Технический стек
- **SQL** (PostgreSQL) 
- **DBeaver** 
- **Yandex DataLens** 
- **CTE (Common Table Expressions)**

## 📊 Ключевые выводы

### 1. Динамика продаж по времени активности

#### Санкт-Петербург:
- **Большинство квартир (41%) продается более полугода** - это крупные объекты с высокой стоимостью
- **Быстрые продажи (до 3 месяцев):** 32% объявлений
- **Высокая цена квадратного метра** во всех категориях
- **Большая средняя площадь** - 63-65 кв.м

#### Ленинградская область:
- **Доминируют продажи до 3 месяцев** (47%)
- **Средняя цена за кв.м выше**, но общая площадь меньше (51-55 кв.м)
- **Медианное количество комнат = 1** - преобладание студий/апартаментов

### 2. Сезонные тенденции

#### 📈 Пиковые периоды:
- **Публикация объявлений:** октябрь-ноябрь (осенний всплеск)
- **Продажи:** октябрь-ноябрь (совпадение с активностью публикаций)

#### 📉 Спады активности:
- **Публикация:** январь, март-апрель
- **Продажи:** май-июнь (подготовка к отпускам)

#### 💰 Ценовая динамика:
- **Наивысшие цены:** осенне-зимний период
- **Наиболее выгодные покупки:** летние месяцы (средняя цена ниже на 15-20%)

### 3. Анализ локаций Ленобласти (Топ-15)

#### 🏆 Лидеры по активности:
1. **Кудрово, Мурино, Шушары** - ближайшие к СПб, наличие/планы метро
2. **Высокая доля продаж** в этих же локациях (60-70%)

#### 💎 Премиальные районы:
- **Сестрорецк** (Курортный район): 105 000 руб/кв.м
- **Пушкин:** 98 500 руб/кв.м
- **Большая средняя площадь** (68-72 кв.м)
- **Бизнес-класс**, элитная недвижимость

#### 💰 Бюджетные локации:
- **Мурино, Кудрово, Бугры:** 65 000-70 000 руб/кв.м
- **Малая средняя площадь** (48-52 кв.м)
- **Эконом-класс**, массовая застройка

#### ⚡ Скорость продаж:
- **Самые быстрые:** Выборг (82 дня) - низкие цены
- **Самые долгие:** Шушары, Мурино (95-98 дней) - большой выбор

## 🎯 Стратегические рекомендации

### Для продавцов:
1. **Время выставления:** октябрь-ноябрь
2. **Ценовая стратегия:** 
   - СПб: умеренное завышение с готовностью к торгу
   - Ленобласть: конкурентные цены для быстрой продажи
3. **Ускорение продаж:** снижение цены на 5-7% ускоряет продажу в 2-3 раза

### Для покупателей:
1. **Лучшее время покупки:** май-июль (низкие цены)
2. **Бюджетные варианты:** Мурино, Кудрово, Шушары
3. **Инвестиции в элитную недвижимость:** Сестрорецк, Пушкин
4. **Быстрые сделки:** Выборг (низкие цены, высокая ликвидность)

### Для агентства:
1. **Фокус на быстрых продажах:** сегмент до 3 месяцев в Ленобласти
2. **Сезонное планирование:** 
   - Осень: акцент на продавцов
   - Лето: акцент на покупателей
3. **Географическая специализация:**
   - Отдельная команда для Курортного/Пушкинского районов
   - Массовое обслуживание в ближайших пригородах
4. **Маркетинговая стратегия:** 
   - Осенняя рекламная кампания для привлечения продавцов
   - Летние акции для покупателей
