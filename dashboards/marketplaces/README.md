## Аналитическ дашборд для маркетплейса

### Описание проекта
Проект представлял собой полный цикл создания аналитического продукта — от коммуникации с заказчиком и проектирования до внедрения и написания инструкций. В рамках проекта была проанализирована сложная структура данных (7 связанных таблиц, >500К заказов), выполнена их глубокая очистка и трансформация. На основе согласованных метрик были подготовлены два аналитических датасета, которые легли в основу интерактивного дашборда с системой фильтров. Результатом стал не просто отчет, а готовый к использованию инструмент, снабженный подробной пользовательской документацией.

--- 

- **Анализ данных & ETL:** Python (Pandas, NumPy), SQL
- **Визуализация & Дашборд:** Superset, HTML/CSS для кастомизации
- **Хранение данных:** PostgreSQL (входные данные), CSV (итоговая выгрузка)

### 1. Техническое задание (ТЗ)
**Ссылка:** https://github.com/KatinKod/da_portfolio/blob/main/dashboards/marketplaces/%D0%A2%D0%97%20%D0%BC%D0%B0%D1%80%D0%BA%D0%B5%D1%82%D0%BF%D0%BB%D0%B5%D0%B9%D1%81%D1%8B.pdf 

- **Цель проекта:** Разработать интерактивный аналитический дашборд для мониторинга ключевых бизнес-показателей маркетплейса, позволяющий выявлять тенденции и принимать обоснованные решения.
- **Целевая аудитория:** Руководители отделов продаж, маркетологи, категорийные менеджеры.
- **Ключевые метрики:** Выручка, количество заказов, средний чек, динамика продаж по категориям и регионам, конверсия в покупку, топ товаров/продавцов.
- **Фильтры:** Диапазон дат, категория товара, регион покупателя/продавца.
- **Логика отображения:** Основной экран — сводная панель с KPI и трендами. Детализация — по клику на элементы графиков или через фильтры.
