# A/B-тестирование нового алгоритма рекомендаций в развлекательном приложении

## Описание проекта

В рамках проекта был спланирован, проведён и проанализирован A/B-тест для оценки эффективности нового алгоритма рекомендаций в развлекательном приложении с функцией «бесконечной» ленты (аналог TikTok или YouTube Shorts).  

**Гипотеза**: новый алгоритм повышает вовлечённость пользователей, что измеряется через долю **«успешных сессий»** — сессий, в которых пользователь просмотрел **4 и более страниц**.

Приложение использует две модели монетизации:
- Ежемесячная платная подписка (без рекламы)
- Бесплатная версия с показом рекламы

Увеличение вовлечённости напрямую связано с ростом вероятности регистрации и конверсии в платную подписку, поэтому метрика «успешная сессия» выбрана как ключевой прокси-индикатор.

## Используемые данные

Анализ выполнен на трёх наборах данных:

| Файл | Период | Назначение |
|------|--------|------------|
| sessions_project_history.csv | 11.08.2025 – 23.09.2025 | Исторические данные для EDA и расчёта базовой конверсии |
| sessions_project_test_part.csv | 14.10.2025 | Данные первого дня теста — для проверки корректности распределения |
| sessions_project_test.csv | 14.10.2025 – 02.11.2025 | Полные данные A/B-теста |

**Структура таблиц** (в исторических данных отсутствует test_group):

- user_id — идентификатор пользователя  
- session_id — идентификатор сессии  
- session_date — дата сессии  
- session_start_ts — точное время начала сессии  
- install_date — дата установки приложения  
- session_number — номер сессии для пользователя  
- registration_flag — зарегистрирован ли пользователь  
- page_counter — количество просмотренных страниц  
- region — регион пользователя  
- device — тип устройства  
- test_group — группа A (контроль) или B (тест)

## Выводы и рекомендации

### ✅ Эффективность алгоритма
Новый алгоритм рекомендаций **статистически значимо улучшает** вовлечённость:
- Абсолютный рост доли успешных сессий: **+1.06**
- Относительный рост: **+3.45%**
- Эффект **превышает заданный MDE (3%)**
- p-value = **0.0003** → высокая уверенность в результате

### ✅ Качество проведения теста
- Группы сбалансированы по всем ключевым признакам  
- Нет технических артефактов (пересечений, смещений)  
- Объём данных и длительность теста — более чем достаточны
