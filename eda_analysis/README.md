# Исследование рынка заведений общественного питания Москвы

## Цели и задачи проекта

Проведение исследовательского анализа рынка заведений общественного питания Москвы с целью выбора заведения для инвестиций на основе данных сервисов Яндекс Карты и Яндекс Бизнес (лето 2022 г.) и дать обоснованные рекомендации по выбору категории, локации и ценовой политики.

---

## Технический стек

- Python
- pandas, numpy
- matplotlib, seaborn
- Jupyter Notebook

---

## Итоговые выводы

1. **Рынок насыщен** заведениями в центре Москвы, особенно кафе и ресторанами.  
2. **Сетевые форматы** доминируют в сегментах **булочных** и **быстрого питания**.  
3. **Высокий рейтинг** не гарантирует высокую цену — связь слабая.  
4. **Средний чек** напрямую зависит от **локации**: ЦАО значительно дороже окраин.  
5. **Топовые сети** сочетают **высокий рейтинг** и **массовость**, особенно в категориях **булочные** и **кафе**.

## Рекомендации инвесторам

✅ **Формат**:  
- Рассмотреть **кафе** или **булочную** — высокий спрос, потенциал для сетевого масштабирования.  
- Избегать перенасыщенных ниш без УТП (например, стандартные пиццерии).

✅ **Локация**:  
- Если цель — **максимизация выручки** → **ЦАО** (но выше конкуренция и арендные ставки).  
- Если цель — **минимизация рисков** → **ЮЗАО, СЗАО** (меньше конкуренции, умеренные цены).

✅ **Ценообразование**:  
- Для ЦАО: **средний чек 900–1 200 руб.**  
- Для окраин: **500–800 руб.**  
- Изучить стратегии **«Буханки»** и **«Кулинарной лавки»** — они успешно сочетают качество, цену и узнаваемость.

✅ **Операционные решения**:  
- Добавить **круглосуточный режим** только при наличии спроса (всего 730 таких заведений).  
- Оптимизировать количество мест: **60–90** — золотая середина для большинства форматов.
