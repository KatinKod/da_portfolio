# Анализ монетизации игры «Секреты Тёмнолесья»

## 🎯 Цель проекта
Провести комплексный анализ игроков онлайн-игры, чтобы понять факторы, влияющие на покупку премиальной валюты «райские лепестки». Результаты должны стать основой для рекомендаций по увеличению конверсии в платящих игроков.

## 📋 Основные задачи
1. Рассчитать общую долю платящих игроков и её распределение по расам персонажей
2. Проанализировать статистику внутриигровых покупок и выявить аномалии
3. Сравнить активность платящих и неплатящих игроков
4. Определить самые популярные эпические предметы
5. Исследовать влияние расы на игровую активность и покупки

## 🛠 Технический стек
- **SQL** (PostgreSQL) 
- **DBeaver** 

## 💡 Ключевые результаты

### 1. Монетизация игроков
- **18%** игроков покупают валюту за реальные деньги
- **Раса персонажа не влияет** на склонность к оплате (доли по всем расам близки)
- **21%** от совершающих покупки - платящие игроки

### 2. Статистика транзакций
| Показатель | Значение |
|------------|----------|
| Всего покупок | 1.3 млн. |
| Средний чек | 525.7 лепестков |
| Медиана | 14 лепестков |
| Максимальная покупка | 486 615 лепестков |

**Проблемы:**
- 907 транзакций с нулевой стоимостью
- 8 770 покупок <1 лепестка
- Сильное смещение данных (медиана в 37 раз меньше среднего)

### 3. Поведение игроков
**Платящие игроки:**
- Совершают меньше транзакций
- Покупают более дорогие предметы
- Высокая доля игроков с огромными тратами

**Неплатящие игроки:**
- Больше транзакций
- Низкая средняя стоимость покупок

### 4. Эпические предметы
**Топ-2 предмета = 98% продаж:**
1. **Book of Legends** - 77% продаж
2. **Bag of Holding** - 21% продаж

**Высокий охват аудитории:**
- 88% игроков купили хотя бы один эпический предмет
- Necklace of Wisdom есть у 11% игроков

### 5. Влияние расы на активность
- **60%** игроков каждой расы совершают покупки
- Разные модели покупок:
  - **Люди/Ангелы**: больше покупок, дешёвые предметы
  - **Эльфы/Северяне**: меньше покупок, дорогие предметы

## 🎯 Рекомендации

- **Сфокусироваться на удержании игроков с огромными тратами** через эксклюзивные предложения
- **Очистить данные** от аномальных транзакций для точного анализа
- **Сегментировать аудиторию** по активности, а не по расе
- **Разные механики для разных групп:**
  - Для активных игроков: бонусы за действия
  - Для стратегов: эксклюзивные дорогие предметы
- **Продвигать непопулярные, но интересные предметы**

## 📊 Итог
Проект показал, что монетизация игры зависит не от выбора расы, а от игрового стиля и вовлечённости. Ключевые направления роста: работа с премиальной аудиторией, балансировка контента и персонализированный маркетинг.
